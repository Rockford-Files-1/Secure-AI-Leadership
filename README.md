# Secure AI Leadership — companion materials (`leaders/`)

Editable versions of the templates in *Secure AI Leadership: A Guide to AI Governance, Risk, and Security Decisions*, by Greg Gogolin, Ph.D., and Erin Hayes (Rockford Files, LLC, 2026), with the completed release record RR-2.2, the questions from every chapter, and a tracker of AI-related obligations.

Purchasers may copy and adapt these materials for use within their own organizations. Names, dates, figures, and identifiers in the completed examples are illustrative; the cases are fictional composites.
